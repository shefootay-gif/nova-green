# 🌿 موقع شركة نوفا جرين (Nova Green) للمنتجات والمستلزمات الزراعية

موقع متكامل وسريع مصمم خصيصاً لشركة **نوفا جرين (Nova Green)** مع لوحة تحكم إدارية مرنة لإضافة وإدارة المنتجات، متوافق بنسبة 100% مع **الخطة المجانية لـ Cloudflare Pages** مع صفر تكاليف استضافة أو تشغيل.

---

## 🌟 مميزات المشروع

1. **تصميم احترافي مطابق للفيديو والهوية:**
   - استخدام اللوجو الأصلي للشركة عالي الدقة.
   - ألوان الهوية: الأخضر الليموني (`#88C025`)، الأزرق السماوي (`#22A3E2`)، والأخضر الداكن الطبيعي (`#13331c`).
   - خط **Cairo** العربي المتناسق والأنيق.
2. **كتالوج المنتجات التفاعلي:**
   - محمل مسبقاً بكافة الـ **17 منتجاً زراعياً المعتمدة** مع تصنيفاتها وموادها الفعالة بدقة.
   - بحث حي وفوري باسم المنتج أو المادة الفعالة.
   - فلترة ذكية بحسب التصنيف الزراعي.
   - زر **"استفسر عن المنتج"** مرتبط بواتساب يرسل اسم المنتج ومادته الفعالة تلقائياً.
3. **لوحة تحكم إدارية سهلة وآمنة (`/admin`):**
   - تسجيل دخول مشفر بكلمة مرور.
   - إضافة منتجات جديدة وتحديد المادة الفعالة والتصنيف.
   - رفع وتغيير صور المنتجات مباشرة من الجهاز مع معاينة حية.
   - تعديل، حذف، وتغيير حالة عرض المنتج.
   - إمكانية استعادة المنتجات الـ 17 الأصلية بضغطة زر واحدة.
   - إمكانية تغيير كلمة مرور المشرف في أي وقت.
4. **🔒 أمان وحماية بيانات المستخدمين:**
   - تطبيق قواعد الأمان الصارمة: عدم تسريب كلمة المرور أو الهاش في أي استعلام أو استجابة عامة، واستخدام التشفير الرقمي `SHA-256` عبر Web Crypto API.
5. **توافق كامل مع الخطة المجانية لكلودفلير (Cloudflare Free Tier):**
   - حجم الحزمة أقل من 90KB Gzip.
   - استضافة سريعة على الـ Edge بلا حدود للباندويث وبشهادة SSL مجانية مدى الحياة.

## 🚀 طريقة الرفع على Cloudflare Pages (مجاناً 100%)

### الطريقة الأولى: عبر GitHub (موصى بها للتحديثات التلقائية)
1. قم برفع المشروع على مستودع خاص أو عام في حسابك على GitHub.
2. ادخل إلى لوحة تحكم [Cloudflare Dashboard](https://dash.cloudflare.com/) واختر **Workers & Pages** ثم **Create application** > **Pages** > **Connect to Git**.
3. اختر المستودع، وضع الإعدادات التالية:
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
4. اضغط **Save and Deploy**. ومبروك، موقعك سيعمل فورياً على دومين مجاني مثل `nova-green.pages.dev` مع SSL مجاني!

### الطريقة الثانية: النشر المباشر عبر الأوامر (Direct Upload)
```bash
# بناء المشروع
npm run build

# الرفع المباشر إلى كلودفلير
npx wrangler pages deploy dist --project-name nova-green
```

## 🗄️ ربط قاعدة بيانات Cloudflare D1 (اختياري للخطة المجانية)
إذا رغبت في حفظ المنتجات مباشرة في قاعدة بيانات D1 السحابية بكلودفلير:
1. أنشئ قاعدة البيانات:
   ```bash
   npx wrangler d1 create nova-green-db
   ```
2. نفذ ملف الجداول والبيانات:
   ```bash
   npx wrangler d1 execute nova-green-db --file=schema.sql
   ```
3. أضف الـ binding في لوحة تحكم Pages بإعداد المتغير `DB` إلى `nova-green-db`.
